## Limits and deployment

This is a bounded deterministic parser, not universal Vietnamese comprehension. Unknown clauses, genuinely ambiguous sources, or absent numeric evidence must not produce a misleading generic report. First-sheet and bounded upload limits remain unchanged. Stable row-position ranking is used for ties, not dense rank.

Local tests do not establish that Streamlit Cloud is running the new code. Publish all changes to the app's configured branch and reboot the Cloud app. A missing report endpoint is reported, never replaced with a merge operation.
